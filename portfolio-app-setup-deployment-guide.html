Portfolio App

Complete guide — local development setup & production deployment to VPS with Nginx + PM2 + SSL.

⚠️ Default admin credentials: username admin / password Admin@1234 — change immediately after first login.

Prerequisites

Local MachineNode.js ≥ 18, MySQL 8+, Git, VS Code (optional)
For DeploymentUbuntu 20.04/22.04 VPS, domain name with A record pointed to server IP
1
Local Development Setup
Run the full stack on your own machine in minutes
1
Install backend dependencies
cd portfolio-app/backend
npm install
2
Create MySQL database & import schema
# Login to MySQL
mysql -u root -p

# Inside MySQL shell:
CREATE DATABASE portfolio_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
EXIT;

# Import the full schema (9 tables + seed data)
mysql -u root -p portfolio_db < ../database/schema.sql
3
Create the .env config file
cp .env.example .env

Open .env and fill in:

NODE_ENV=development
PORT=5000
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=your_mysql_password
DB_NAME=portfolio_db

# Generate: node -e "console.log(require('crypto').randomBytes(64).toString('hex'))"
JWT_SECRET=paste_64_char_random_string_here
JWT_EXPIRES_IN=7d

MAX_FILE_SIZE=5242880
UPLOAD_DIR=./uploads
CORS_ORIGINS=http://localhost:5500,http://127.0.0.1:5500
BCRYPT_ROUNDS=12
4
Change default admin password
# Generate bcrypt hash for your new password:
node -e "const b=require('bcryptjs'); b.hash('YourNewPass!',12).then(console.log)"

# Update in MySQL (paste the output hash):
mysql -u root -p portfolio_db -e \
  "UPDATE users SET password_hash='PASTE_HASH_HERE' WHERE username='admin';"
5
Start the backend server
# Development (nodemon — auto-restart on save)
npm run dev

# Production
npm start
  • API running at http://localhost:5000
  • Health check: http://localhost:5000/api/health
6
Open the frontend
# Option A: VS Code Live Server (recommended)
# Right-click frontend/portfolio/index.html → "Open with Live Server"
# Default URL: http://127.0.0.1:5500

# Option B: npx serve (no install needed)
npx serve frontend/portfolio -p 3000   # Portfolio
npx serve frontend/admin    -p 3001   # Admin

# Option C: Python
cd frontend/portfolio && python -m http.server 3000
Portfolio URLhttp://127.0.0.1:5500
(or localhost:3000)

Production Deployment (Ubuntu VPS)
Nginx reverse proxy + PM2 process manager + Let's Encrypt SSL
1
Server prep — Node.js 20 + MySQL + Nginx
ssh root@YOUR_SERVER_IP
apt update && apt upgrade -y

# Node.js 20
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt install -y nodejs

# MySQL 8
apt install -y mysql-server
mysql_secure_installation

# Nginx
apt install -y nginx
systemctl enable nginx && systemctl start nginx

# PM2
npm install -g pm2
2
Create dedicated database user
mysql -u root -p

CREATE DATABASE portfolio_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'portfolio_user'@'localhost' IDENTIFIED BY 'StrongDbPass!';
GRANT ALL PRIVILEGES ON portfolio_db.* TO 'portfolio_user'@'localhost';
FLUSH PRIVILEGES;
EXIT;
3
Upload project & install dependencies
# From LOCAL machine — upload via SCP:
scp -r portfolio-app/ root@YOUR_SERVER_IP:/var/www/portfolio-app

# OR via Git on the server:
cd /var/www
git clone https://github.com/yourusername/portfolio-app.git

# On server — install backend deps:
cd /var/www/portfolio-app/backend
npm install --production

# Import schema:
mysql -u portfolio_user -p portfolio_db < /var/www/portfolio-app/database/schema.sql
4
Create production .env
nano /var/www/portfolio-app/backend/.env
NODE_ENV=production
PORT=5000
DB_HOST=localhost
DB_USER=portfolio_user
DB_PASSWORD=StrongDbPass!
DB_NAME=portfolio_db
JWT_SECRET=your_64_char_random_secret
JWT_EXPIRES_IN=7d
MAX_FILE_SIZE=5242880
UPLOAD_DIR=./uploads
CORS_ORIGINS=https://yourdomain.com,https://www.yourdomain.com
BCRYPT_ROUNDS=12
5
Update API base URL in frontend JS files

Edit these two lines in each file:

FileVariableNew value
admin/js/auth.jsconst API'https://yourdomain.com/api'
admin/js/dashboard.jsconst API'https://yourdomain.com/api'
portfolio/js/main.jsconst API'https://yourdomain.com/api'
portfolio/js/main.jsconst BASE'https://yourdomain.com'
6
Start backend with PM2
cd /var/www/portfolio-app/backend

pm2 start server.js --name "portfolio-api"
pm2 startup    # generates systemd service command — run that output command
pm2 save       # persist process list across reboots

Useful PM2 commands:

pm2 status                   # view all processes
pm2 logs portfolio-api       # live logs
pm2 restart portfolio-api    # restart
pm2 monit                    # CPU/RAM dashboard
7
Configure Nginx virtual host
nano /etc/nginx/sites-available/portfolio
server {
    listen 80;
    server_name yourdomain.com www.yourdomain.com;

    # ── Portfolio (public site) ─────────────────────────────
    root /var/www/portfolio-app/frontend/portfolio;
    index index.html;
    location / {
        try_files $uri $uri/ /index.html;
    }

    # ── Admin dashboard ─────────────────────────────────────
    location /admin/ {
        alias /var/www/portfolio-app/frontend/admin/;
        try_files $uri $uri/ /admin/index.html;
    }

    # ── API reverse proxy ────────────────────────────────────
    location /api/ {
        proxy_pass         http://localhost:5000;
        proxy_http_version 1.1;
        proxy_set_header   Upgrade $http_upgrade;
        proxy_set_header   Connection 'upgrade';
        proxy_set_header   Host $host;
        proxy_set_header   X-Real-IP $remote_addr;
        proxy_set_header   X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header   X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
    }

    # ── Uploaded files ───────────────────────────────────────
    location /uploads/ {
        alias /var/www/portfolio-app/backend/uploads/;
        expires 30d;
        add_header Cache-Control "public, immutable";
    }

    # ── Upload size limit ────────────────────────────────────
    client_max_body_size 10m;

    # ── Security headers ─────────────────────────────────────
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;

    # ── Gzip ─────────────────────────────────────────────────
    gzip on;
    gzip_types text/plain text/css application/json application/javascript;
    gzip_min_length 256;
}
ln -s /etc/nginx/sites-available/portfolio /etc/nginx/sites-enabled/
nginx -t              # Must output: syntax is ok
systemctl reload nginx
8
Install SSL with Let's Encrypt (Certbot)
apt install -y certbot python3-certbot-nginx

# Issue certificate (follow prompts — choose "Redirect HTTP to HTTPS")
certbot --nginx -d yourdomain.com -d www.yourdomain.com

# Test auto-renewal
certbot renew --dry-run
✅ Your site is now live at https://yourdomain.com with HTTPS!

Troubleshooting

Error / SymptomFix
MySQL connection refused Run sudo systemctl start mysql
CORS error in browser console Add your frontend origin (e.g. http://127.0.0.1:5500) to CORS_ORIGINS in .env, then restart backend
Port 5000 already in use Change PORT in .env and update const API in all frontend JS files
413 Request Entity Too Large Add client_max_body_size 10m; to Nginx config. Also raise MAX_FILE_SIZE in .env
PM2 app not starting Run pm2 logs portfolio-api to see the error. Most common: missing .env or wrong DB password
401 Unauthorized (admin) JWT expired — log out and log back in. Token is valid for JWT_EXPIRES_IN (default 7 days)
Images not showing in production Check Nginx location /uploads/ alias path matches actual uploads folder on disk
Slug already exists (409) Two projects have the same title. Slightly change the title to generate a unique slug
